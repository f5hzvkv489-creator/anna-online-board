
# AnnaBoard

Полноценная платформа репетитора по математике.

## Возможности
- Бесконечная доска
- Папки и доски
- Совместная работа
- PDF как фон
- Формулы LaTeX
- Геометрические фигуры
- История изменений
- Экспорт PDF/PNG
- Firebase синхронизация

## Технологии
- Next.js
- TypeScript
- tldraw SDK
- Firebase
